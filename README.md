## 📖 Program Overview

The **AI Administrator Track** is an executive and technical training initiative designed by the **IEEE Computer Society Region 8 (Europe, Middle East, and Africa)**. 

While conventional AI courses focus on writing prompts for casual chat interfaces, this program trains engineers and operations professionals to design, evaluate, and deploy **repeatable, autonomous, and tool-augmented agentic workflows**.

Participants progress from understanding raw LLM boundaries to building production-grade n8n automations, deploying Retrieval-Augmented Generation (RAG) assistants, and orchestrating multi-agent systems with formal supervision.

## 🛠️ Required Platforms & Zero-Code Tooling

All exercises are designed to run in cloud-hosted web interfaces without local installation overhead:

1. **[Google AI Studio](https://aistudio.google.com/):** Free developer sandbox for testing Gemini models, system instructions, document grounding, and temperature tuning.
2. **[n8n Automation Engine](https://n8n.io/):** Node-based workflow automation platform (Cloud or Desktop).
3. **Spreadsheet Application:** Google Sheets or Microsoft Excel for building evaluation test benches.
4. **GitHub Account:** To fork this repository, submit lab deliverables, and participate in technical discussions.

---

## 📋 Course Deliverables & Certification Protocol

For each session, complete the designated lab and upload your artifact into the corresponding directory:

1. **`M1-task-inventory` (Due Session 2):** Spreadsheet cataloging 10 workplace tasks with judgment scores and design recommendations.
2. **`M2-prompt-library` (Due Session 3):** 5-part prompt library document, 10-row classification test bench (before/after), trap-test audit table, and verified screenshot.
3. **`M3-workflow-map` (Due Session 5):** End-to-end operational diagram showing human-in-the-loop and automated validation steps.
4. **`M4-n8n-pipeline` (Due Session 7):** Exported n8n JSON workflow file processing incoming mock emails or webhooks.
5. **`M5-agent-tools` (Due Session 9):** System instruction configuration granting least-privilege tools.
6. **`M6-final-capstone` (Due Day 6):** Complete enterprise assistant audit report with test bench evaluation metrics.
